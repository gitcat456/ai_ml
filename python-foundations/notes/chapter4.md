## Important Concepts

### Scope Rules

- Global code cannot access local variables.
- One local scope cannot access another local scope.
- Local code can access global variables.
- Variables with the same name can exist in different scopes.

### Return Behavior

- Functions return values.
- Functions without return statements return None.
- return immediately exits a function.

### Exception Handling

- try contains risky code.
- except contains recovery code.
- Prevents programs from crashing unexpectedly.

## Common Errors

- NameError
- UnboundLocalError
- ZeroDivisionError
- Forgetting return statements
- Accidentally shadowing global variables
- Using local variables outside their scope

## AI/ML Relevance

- Functions are used to build reusable preprocessing pipelines.
- ML projects are organized almost entirely around functions.
- Exception handling is important when loading datasets.
- Scope management becomes critical in large codebases.
- Training, validation, and prediction steps are usually separate functions.
